# Monitoring and Operations
## Framework Review: Operational Excellence
- **AWS Systems Manager (SSM)**: Session Manager provides secure, auditable, bastion-free SSH-equivalent access to EC2 instances. 
- **Amazon CloudWatch**: Gathers metrics (ALB 5xx errors, TargetResponseTime, CPUUtilization).
- **Amazon SNS**: Alerts operations teams during critical CloudWatch Alarm thresholds.
